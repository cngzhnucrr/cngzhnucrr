#### 💻 Haftalık Kodlama İstatistikleri (WakaTime)

Eğer kodlama süreni takip etmek istersen **WakaTime** harika bir araç! [citation:11]

1. [WakaTime](https://wakatime.com/)'a kaydol
2. VS Code/IDE'ine WakaTime eklentisini kur
3. API key'ini al
4. Aşağıdaki kodu README'ne ekle:

```markdown
<!-- WAKATIME VERİLERİ -->
<div align="center">
  <img src="https://wakatime.com/share/@cngzhnucrr/7a8f9b1c-2d3e-4f5a-6b7c-8d9e0f1a2b3c.svg" width="48%" />
```
